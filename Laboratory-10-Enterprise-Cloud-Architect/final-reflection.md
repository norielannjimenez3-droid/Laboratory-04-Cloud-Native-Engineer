# Final Reflection: Missions 1–10

Throughout Missions 1 to 10, I developed a better understanding of cloud computing, Linux administration, containerization, security, and automation. The earlier missions introduced me to fundamental cloud and server concepts, while the later activities helped me apply those concepts to practical deployment and operational tasks.

One of my most important lessons was learning how to deploy and manage applications using Docker and Docker Compose. Instead of configuring every component manually, I could define the service configuration in a YAML file and use repeatable commands to start, inspect, and stop the application. I also learned that containerization alone does not guarantee security. Firewall rules, limited network exposure, software updates, and proper file permissions are important parts of a secure deployment.

Creating a Bash backup script showed me how automation can reduce repetitive work and improve operational consistency. By combining the script with Cron, I could schedule backups without manually running the command every day. However, automation also has risks. Incorrect paths, excessive permissions, insufficient disk space, and faulty retention rules can cause failures or data loss. For this reason, scripts should be tested, logged, and monitored.

I also learned the difference between Bash and Docker Compose. Bash is useful for executing sequential commands, checking conditions, and automating maintenance tasks. Docker Compose is designed to define and manage containerized services. Together, they provide a more manageable operational workflow.

Across the ten missions, I progressed from learning individual tools to understanding how deployment, security, maintenance, and recovery work together. Writing an operational manual reinforced the importance of documentation because another IT technician should be able to maintain the system without relying on the original developer.

My preferred career direction is cloud engineering or DevOps. I want to continue improving my skills in Linux, container orchestration, infrastructure automation, monitoring, and disaster recovery. These missions have given me a practical foundation for building systems that are more secure, repeatable, and reliable.
