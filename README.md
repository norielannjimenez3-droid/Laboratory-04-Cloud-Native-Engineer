# Laboratory 04 — Cloud-Native Engineer

## Mission Overview

This laboratory focuses on the fundamental concepts of cloud-native engineering, including virtualization, containers, and Docker. In this activity, Virtual Machines and containers are compared, followed by a demonstration of how Docker can be used to deploy an Nginx web server quickly and efficiently.

## Objectives

The main goals of this laboratory are to:

- Learn the differences between Virtual Machines and containers.
- Understand the advantages of using containers.
- Check if Docker is properly installed and working.
- Download an official image from Docker Hub.
- Set up an Nginx web server inside a Docker container.
- Learn how to manage the lifecycle of Docker containers.
- Record and explain technical procedures using Markdown.
- Develop and organize my technical skills portfolio through GitHub.
