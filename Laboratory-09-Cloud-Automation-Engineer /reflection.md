# Mission Reflection

Throughout this Cloud Computing course, I have learned that managing cloud infrastructure involves more than simply creating virtual machines or running applications. Automation, security, storage, networking, and reliable system administration are all important parts of building and maintaining cloud environments.

Automation is critical when managing hundreds of cloud servers because performing repetitive tasks manually takes too much time and increases the possibility of human error. Using Bash scripts and scheduled tasks allows administrators to perform operations, such as backups and maintenance, consistently. This helps IT teams save time and focus on more important responsibilities.

However, automation also has potential dangers. A destructive typo in a script scheduled to run on 1,000 servers could delete important files, interrupt services, or cause significant data loss across an entire infrastructure. This is why scripts should be tested in a safe environment, reviewed by another person when possible, and deployed gradually. Backups, monitoring, access controls, and recovery plans are also essential safeguards.

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. Bash scripting uses commands, variables, and conditional statements to perform tasks step by step. Docker Compose uses YAML to describe application services, configurations, networks, and volumes. Bash focuses on executing instructions, while Docker Compose focuses on defining how containers should run together.

Reviewing my GitHub repository from Laboratory 1 to Laboratory 9 has helped me understand how different cloud technologies work together. My understanding has grown from learning individual commands and basic infrastructure concepts to recognizing the importance of deployment, storage, security, networking, and automation in real-world cloud environments.

The role I enjoyed most was the Cloud Automation Engineer because I liked learning how scripts and scheduled tasks can simplify repetitive work. I also realized that automation requires careful planning and testing because one mistake can affect many systems. Overall, this semester improved my technical confidence and helped me appreciate the skills needed to manage cloud infrastructure efficiently, securely, and reliably.
