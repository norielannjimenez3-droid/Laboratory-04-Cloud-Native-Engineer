# Checkpoint 2: Research — The Language of Automation

## 1. Bash Script

A Bash script is a text file containing a series of Linux commands that can be executed together to automate tasks. The `#!/bin/bash` line at the beginning of the file is called a shebang, which tells the operating system to use the Bash shell to interpret and run the commands in the script.

## 2. Variables

Variables are used to store values, such as folder paths, filenames, or configuration settings, so programmers do not have to type the same information repeatedly. For example, `$BACKUP_DIR` can store the location of a backup folder, making the script easier to read, update, and maintain if the destination changes.

## 3. Cron Job

A cron job is a scheduled task in Linux that automatically executes a command or script at a specified time or interval. It is essential for cloud operations because it allows administrators to automate recurring tasks, such as backups, system maintenance, and monitoring, without needing to run them manually each time.
